# Pagliaroom

Static website (HTML/CSS/JS, no build step; three.js loaded from jsDelivr).

## Publish on GitHub Pages
1. Create a repo and upload all files in this folder (keep `assets/`).
2. Settings > Pages > Deploy from a branch > `main` / root.

Change the contact email: search `hello@pagliaroom.com` in `index.html`.
