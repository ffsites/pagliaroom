# Pagliaroom

Static website (HTML/CSS/JS, no build step).

## Publish on GitHub Pages
1. Create a repo and upload all files in this folder (keep `assets/`).
2. Settings > Pages > Deploy from a branch > `main` / root.
3. Open the URL GitHub gives you.

To change the contact email, search `hello@pagliaroom.com` in `index.html`.
